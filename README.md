# Financial Bloom

A full-stack Budget Tracker application.

## Structure

- `backend/` - FastAPI + SQLite
- `frontend/` - React + Vite

## Running

See individual README files in backend/ and frontend/.

## Releases

This chart is released through Replicated. CI auto-bumps the chart
version on every PR opened against `main` and creates a corresponding
release in the Unstable channel.
